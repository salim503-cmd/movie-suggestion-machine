# Movie Suggestion Machine

Files: index.html (the app), api/recommend.js (server function), manifest.json + sw.js + icons (installable app).

Setup: 1) get a free TMDB "API Read Access Token". 2) Upload these files to a GitHub repository.
3) Import the repo on vercel.com and add an Environment Variable named TMDB_TOKEN with your token. 4) Deploy.

This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming data by JustWatch.
